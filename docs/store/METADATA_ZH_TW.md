# 商店素材草稿

狀態：PREPARED。只寫檔，未上傳。候選名稱與副標均少於 30 字。

名稱：陽光農場：籃底的手記

副標題：追一道光，留一籃收穫給鄰居

關鍵字：農場,像素,種田,陽光,餐籃,手記,鄰居,放置,離線,料理,釣魚,鄉村,休閒,故事

## 說明

光落在哪一格，就去那裡種麥、澆水，讓作物多長一截。
第一份收成先留兩份，替葛瑞裝一籃；留在門邊，或邀他一起坐下。
兩種送法，兩頁不同的祖母便箋。你選的那一頁會留在日誌裡。

祖母留下的農場有點荒了，河畔的釣台和桌子也等著人修。種下小麥、照顧動物，再把收穫做成料理，慢慢把鄰居找回來。

田裡的陽光光斑只停留一小段時間。在光裡種植或澆水，作物會長得更快；在光裡收成，還能多收一份。錯過這一道，下一道還會再來。

想玩一會兒，可以做今日農務、送餐籃、集印章。想待久一點，就去釣魚、料理、修復河畔。印章不用連續登入累積，三枚和七枚各有一頁祖母手記。

進度保存在裝置上，不用註冊帳號。遊戲沒有廣告或追蹤；網頁版本完成首次下載與快取後可離線遊玩。離開時作物仍會生長，已解鎖的幫手機器人可帶來最多八小時的離線收益。

# 陽光農場：籃底的手記

日期：2026-10-15。狀態：VERIFIED（本機玩法）；Apple 4.3 風險：**高**。

核心玩法一句話：**等光落在田裡，親手在光裡種麥或澆水，收成後替鄰居留一籃，讓你的送法成為祖母手記的下一頁。**

## 前三分鐘的實質差異

開場直接選「做第一份陽光餐籃」。專屬任務卡把光斑、種植、收成與分享串起來：種下小麥後約四秒出光，光裡的種植或澆水會推進生長；該株的陽光照料記錄保留到收成。成功入庫至少兩份後，交付取走倉庫兩份小麥。玩家選「留在門邊」或「一起坐下」，角色走到葛瑞身邊，作用幀才結算；兩種選擇留下不同的手記與葛瑞回應。

這段不是審查專用模式，所有新玩家都看到相同入口；既有玩家也可在「日誌 → 陽光餐籃」開始。沒有預先給成熟作物、沒有自動贈送餐籃，也不用等三天或七天。完成後回到既有九項河畔復興主線，手記永久保留。每日餐籃與 3／7 枚印章的兩頁收藏繼續存在。

證據：[審查員路徑程式](../../scripts/test-r81-review.js)、[執行結果](../evidence/r81-store/review-results.json)。時間是無頭真觸控流程的實測，並非玩家平均完成時間。截圖沒有注入農務或收藏進度。

## 同類作品與玩家在這裡得到的內容

2026-10-15 查閱官方介紹，未據此宣稱全市場唯一或當日排行：

- [Hay Day 官方](https://supercell.com/en/games/hayday/) 介紹作物、動物、加工交易與分享等農場體驗。種植、每日目標、訂單或鄰里本身不能當差異。本作可具體展示的是「16 秒光斑中的照料 → 該株收成 → 實物餐籃 → 送法分歧的便箋」這段組合。
- [Stardew Valley 官方](https://www.stardewvalley.net/about/) 已有繼承農場、鄉村生活與居民故事。像素畫面、繼承祖輩農場和村民關係也不能當唯一性主張。本作提供較短的開場路徑，讓第一次收成直接接到兩種送法與永久手記；這是本作已實作內容的定位，並非證明其他遊戲完全沒有類似系統。

只能在這個作品讀到的具體創作，是「門邊那一籃」與「多擺一張椅子」兩則祖母便箋、對應的葛瑞回應，及其連到既有晨光鎮河畔復興的脈絡。不能把兩則文字與配色調整稱為整個農場類型的突破。

# 陽光農場 內容優化 R83 計畫（精簡版）

依據 R82 評審：Codex 8.1、Claude 6.4（`REVIEW_CONTENT_R82.md`）。三輪 Codex 都停在 8.1，主要被「看得到的錯」拖住；這一輪先把會讓玩家讀不懂、卡住的錯修乾淨，再讓兩條舊麥種路線與田邊小事「看得到」。評審仍只用 Codex 一次＋Claude 一次，完整測試只在收尾跑一次。

## A 線（Codex）：任務卡讀得懂、主線跟著劇情走
1. 收合任務卡不疊字：任務名稱與短句不得畫在同一位置；收合時標題列只顯示一種文字（短句優先），右側狀態（等光再收、0/1）不重疊。R82 圖 3、4、11、13、14、30、69、91、92、97～100、105、107、128、130、133、144、146 都要能讀。
2. 拿掉鄰居好感故事對話時任務卡下方的兩張空白卡片（R82 圖 114、120），找出是哪個元素並修根本原因。
3. 主線跟著劇情走：把餐籃交給鎮長、或演完任何一段跟鎮長葛瑞的舊麥種劇情，就算「找鎮長葛瑞交談」完成，鎮長頭上的「!」跟著消失。
4. 手機收合的祖母手記卡要看得到短句，不能只剩「1/3」；收合時也要看得到「還有另一件可挑」的提示（例如主鈕旁小字或一顆次要小鈕），不得擠掉短句。
5. 手機右下大鈕：任務正在引導某個目標、而角色身旁的互動物不是那個目標時，大鈕不得搶寫別的東西（R82 圖 161「使用・告示牌」）。
6. 同一畫面不得出現互相矛盾的狀態：「還沒成熟」與「可收成」不同時出現（圖 132）；空地不出現「收成」鈕（圖 83）；任務卡文字與按鈕講同一件事（圖 41、54～56、127）。
7. 測試：`scripts/test-content-r83-card.js`（規則）、`scripts/test-content-r83-card-layout.js`（四尺寸實拍收合／展開不疊字、無空白卡）。

## B 線（Codex）：兩條舊麥種路線看得到成果
1. 藍布老麥名牌照階段更新：剛種下／照過 1 次光／可以收成／已收成；成熟時外觀明顯不同（例如麥穗發光、加一圈金色光點），64px 縮圖分得出。
2. 收成藍布老麥時，選這條路的老農班伯說一句話（帶頭像）；專屬訂單名稱對應做選擇的鄰居。
3. 鎮誌三樣舊物畫成看得清楚的地圖物件（至少跟藍布舊麥種包一樣大），完整在畫面內、名牌寫「鎮誌 1／3」且不與其他名牌重疊；每樣舊物的回憶由鎮長葛瑞本人說（帶頭像），旁白只做補充。
4. 選項文字只講「地圖會多什麼、之後能做什麼」，數字留在手札（沿用 R82 規則，檢查還有沒有漏的）。
5. 測試：`scripts/test-content-r83-branches.js`。

## C 線（Claude 子代理）：教學一套說法、田邊小事長在地圖上
1. 前十分鐘的任務卡、田上標籤、祖母手記、提示訊息，講光只用「折光／等光再收／在光裡收成／在光裡澆水」這一組；拿掉「光到了再澆水」「看見光落下再去澆水」這類跟教學順序衝突的說法；教等光時不跳「手鏡可折 1 次」。
2. 田邊小事改成地圖上的東西：麻雀、雜草、落穗、枯枝直接畫在田邊地上（用已有的 MUSE 圖 `content-r82/chore-sparrow.png`、`chore-weed.png` 與現有素材），有輕微動作（麻雀跳、雜草晃），不再是介面小方塊；不壓角色、不壓按鈕。
3. 至少一種小事有小取捨：例如麻雀可以「趕走」或「留一把穗給牠」，留穗的話之後偶爾帶回一顆種子；結果寫進手札。
4. 測試：`scripts/test-content-r83-play.js`。

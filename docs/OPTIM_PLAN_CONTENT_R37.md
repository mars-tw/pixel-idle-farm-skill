R36 退步的主因（三方都列嚴重）：市集開放時，里程碑卡排在前面，老農班伯的對話被延後；玩家打開訂單後，卡片一收，對話立刻跳出，畫面只剩對話、看不到面板。另有：里程碑卡寫「前往訂單看板」，任務列卻寫「前往料理」，兩個下一步互相衝突。

## 0. 整合者前置修正（Claude，已完成）
- 結算／里程碑卡顯示時，玩家按到任何其他地方，卡片先收起，不攔截操作。
- 側邊面板、「更多」選單或對話窗開著時，排隊中的 NPC 對話延到它們關閉後才出現（原本對話一跳出就把「更多」選單關掉，玩家點不到訂單分頁）。
- 「市集開放」里程碑卡的下一步改成與任務列一致：「照任務列去灶台做晚餐；訂單看板之後隨時可以接單。」

## A 線：文案與系統（派 Codex）
1. **前置修正的單元測試**：新增測試鎖住第 0 項的三個行為（原始碼與模擬：卡片在畫面上時，點到其他元素就關閉卡片；面板、「更多」選單、對話窗開著時 `speak` 延後；市集開放下一步與任務列同向）。
2. **市集預告不搶主線**：市集未開放時，預告卡加上「預覽・尚未開放」字樣。主要按鈕依持有量切換：小麥未滿 2 份時寫「先收成小麥（持有 X/2）」並帶玩家去田；滿 2 份才寫「前往老農班伯」。
   - 驗收：單元測試新存檔持有 0 份與 2 份兩種狀態，按鈕文字與動作不同。
3. **每日印章冊字句**：表頭改成「今天可做 N 項・達成 X・已領 Y」，不再出現「已完成 2/2」與「已領取 0/2」並列；每項都顯示「目前／目標」數字（含「賣出一份作物 0/1」）。
   - 驗收：單元測試與字串。
4. **對話主次分明**：對話框的「繼續 ▶」為主要按鈕（較大、實心）；「略過」改為次要的小字按鈕。
   - 驗收：字串與 CSS 規則存在。
5. **中期只有一個主要下一步**：交完第一章後，任務列、里程碑卡與 NPC 台詞指向同一件事。老農班伯「別只顧著賣」那句改為呼應料理任務，不再暗示和訂單衝突。
   - 驗收：單元測試掃描第一章完成後產生的里程碑卡、任務列按鈕與對話文字，三者都指向料理。

## B 線：畫面（派 MUSE）
6. **UI 不蓋田（所有步驟）**：1366×768 與 1366×600 在播種、澆水、回報、收成每個步驟，任務列、種子欄、「＋全部」都不蓋任何田格。種子欄只在播種步驟或玩家手上拿種子時展開，其他時間收成一個小按鈕。
   - 驗收：瀏覽器在四個步驟量測所有田格與任務列、種子欄的交集為 0。
7. **角色不疊在一起**：玩家走到 NPC 旁邊交談或交付時，停在 NPC 左右相鄰格，不與 NPC 重疊；名牌不被房子蓋住。
   - 驗收：中期畫面量測玩家與班伯的精靈圖交集 ≤ 10%。
8. **建造模式占地預覽**：選中建物後，游標或觸控位置顯示建物占地格。可放的格子呈綠色，不可放的格子呈紅色，並顯示「花費 X・剩 Y」。
   - 驗收：瀏覽器在空地與建物旁各量測一次，預覽元素存在且顏色狀態不同。
9. **手機 HUD**：844×390 的頂部資源列依內容縮短，不留大段空白；390×844 底部工具列文字至少 11px。
   - 驗收：量測。
10. **場景清理**：移除樹樁旁的深色暈影（降到幾乎看不出來或直接移除），並修正被房子蓋住的 NPC 名牌。
    - 驗收：截圖與量測。

# 陽光農場 R32 優化計畫：畫面減量、名牌不認錯人、每個入口都有事可做

版本 **0.1.55**／`content-r32-20261105-1`，基準 R31（`93ffe6b`）。

三方最一致的扣分是「同時在畫面上的東西太多」：手機任務卡、工具列、方向鍵、互動鍵、種子欄一直常駐；長面板靜態畫面看起來像被切斷。另有一個 R30 引入的錯誤：名牌與角色重疊時「往上移」，玩家站在鎮長上方時名牌被推到玩家頭上，看起來像玩家叫葛瑞。

## A 線：每個入口都有事可做、回饋看得見（派 Codex）
1. **市集未開放時顯示預告訂單**：訂單面板不再只有一行說明，改為 2～3 張灰色「預告訂單卡」（品項、報酬、解鎖條件與目前進度，例如「交給班伯 0/2」），加一個主要按鈕「前往班伯」。
   - 驗收：單元；新存檔打開訂單有一個可點的主要動作。
2. **建造第一次進入就有可做的事**：新存檔第一次打開建造，至少有一項買得起（或可免費試放一次的小物件）。
   - 驗收：單元：新存檔 `canBuild` 至少一項為真。
3. **金幣與物品增減都有飄字**：每次入帳、扣款、拿到或用掉物品，在對應 HUD 欄位旁飄出「＋12 金」「－2 小麥種子」，同一時間合併為一則。升級會花光全部金幣時，按鈕下方提醒一行。
   - 驗收：單元檢查事件會產生飄字資料。
4. **手記與設定細節**：
   - 故事手記把進行中的任務排在最上面，下一段劇情按鈕放在該任務下方。
   - 設定開關旁顯示至少 12px 的「開／關」文字。
   - 驗收：單元。
5. **稱呼一致**：葛瑞一律寫「鎮長 葛瑞」，班伯一律寫「老農 班伯」，任務卡、對話、訂單、手記都用同一稱呼。
   - 驗收：單元掃描字串。

## B 線：畫面減量與名牌（派 MUSE）
6. **名牌不認錯人**：名牌與玩家或其他角色重疊時，改放到該 NPC 的左側或右側（仍有指向三角），絕不放到另一個角色頭上。
   - 驗收：瀏覽器測試：玩家站在鎮長正上方、正下方、左右四種位置，名牌中心與鎮長頭頂水平距離 ≤ 16px（側放時以指向三角量測），且玩家頭頂 24px 內沒有 NPC 名牌。
7. **手機常駐元件減量**：
   - 方向鍵預設隱藏（點地圖即可移動），設定加「顯示方向鍵」開關；
   - 「互動」鍵只在角色旁邊有可互動目標時出現；
   - 手機任務卡預設收成一行，點一下展開。
   - 驗收：390×844、844×390 量測世界可視面積 ≥ 70%。
8. **HUD 不蓋任務目標**：任務目標（田格、NPC）落在任務卡、種子欄、小地圖範圍內時，鏡頭平移讓目標進入安全區；作物浮動標籤不畫在 HUD 區。
   - 驗收：1366×768、1366×600 收成階段量測交集 0。
9. **長面板首屏看起來完整**：升級、手記、訂單面板首屏只放得下的完整卡片，最後以「再顯示 N 項」按鈕取代半張卡片，不再出現被切一半的卡。
   - 驗收：四尺寸量測首屏沒有被面板下緣切到的卡片。
10. **對話框與面板標題**：矮螢幕（高度 ≤ 600）對話框改成上方窄條（高度 ≤ 20% 畫面），不遮田區；面板標題改成一般標題列（不用輸入框樣式）。
    - 驗收：量測與截圖。

## 八大面向

| 面向 | 本輪做／不做與理由 |
|---|---|
| 美術 | 沿用既有像素圖示、紙張與農場素材；收藏採文字手記。沒有新增 2D 圖片，不用程序方塊代替素材 |
| 按鈕 | 做：拇指收成鍵、日誌入口、44px 命中、避免連按中斷與各視口量測 |
| 選單 | 做：今日三張單卡、收藏分頁、固定關閉；背景操作由既有 modal inert 隔離，放置成長照時間推進 |
| 人物 | 不改：本輪重點是農務與回訪，沿用已存在人物圖 |
| 地圖模型 | 不改：使用既有田地與走路路徑，所有新目標接進既有田地和倉庫 |
| 技能 | 做：情境收成顯示數量、忙碌回饋、真正作用幀結算，沿用陽光優先與收成回饋 |
| 角色樣子 | 不改：沒有替換角色素材，跑原有 atlas／夜間閘門 |
| 動作流暢度 | 做：收成快捷沿用逐幀移動與收成動作，連按不重開動作；不新增單圖晃動或假動作 |

## 限制與缺件

- 不新增未取得授權的音樂或音效；沿用現有音效。
- 專用持竿、捧收成動作幀仍屬前輪缺件，本輪不冒稱補齊。
- 效能資料只標「並發載量測，僅供參考」，不宣稱通過出貨效能閘。手機實機手感與留存需要後續真人試玩。
- 只暫存本輪明確路徑；如測試改寫歷史證據，只還原本輪自己造成的變動，保留原有異動。

# R77 NPC 提示與透明圖示修正

版本：`r77-20261002-1`。

原本任務標記的底部比 NPC 圖片頂端低 27px，光點也用固定格高定位，因而蓋住人物。現在依實際 sprite 頂緣留出至少 14px 的間距，光暈與最大 1.3 倍脈動也不進入人物範圍。任務目標 NPC 合併為單一箭頭；可交付委託保持綠色，提示不攔截人物點擊。對話泡泡也使用相同頂緣錨點。

32 張圖示的 alpha 原本已經透明；破圖原因是顯示框縮到 20–28px，背景仍以 256×128px 和固定 32px 座標裁圖。R77 改使用 R66 已存在的單張 `native/*-32.png`，以 contain／center 完整縮放，並解除固定 32px flex-basis。沒有把書頁、木材等物件本體當成背景刪除，也沒有改動來源 PNG。

`scripts/test-npc-indicators.js` 驗證 1440×900、390×844、320×568、844×390，涵蓋未讀、可交付、任務目標、交談，以及 natural／fit 模式。以最大脈動檢查標記和光暈的安全距離，並逐一檢查 32 張 PNG 的透明四角及 20／24／28／32px 縮放。

32 張單圖皆加入 Service Worker 預快取。發布版本與快取 query 一併更新，保留既有存檔及素材來源雜湊。

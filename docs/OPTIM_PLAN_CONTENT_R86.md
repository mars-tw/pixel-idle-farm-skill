# 陽光農場 R86 雨後手記

在手札圖鑑的「追光手冊」裡新增雨後手記。玩家把雨水用在作物上，等雨後虹光落田，再趁虹光還在時收下一份成熟作物。三件事各留一次紀錄，集齊後可讀祖母留下的話。

## 驗收

- 桶水至少澆到一格正在生長且缺水的作物才記錄。倒空桶、田已澆過或作物已成熟都不算。
- 雨後虹光實際落在至少一格田才記錄。只在虹光有效期間、該格仍有光、收成確實進倉時，留下第一種作物的名字。日照、光照預告、過期虹光和收成預估都不算。
- 三筆進度各自保存。重複操作、批次收成或重讀存檔不會再獲得同一筆。R85 舊檔只補登原先已記載的虹光，不從倒桶數或一般收成推測其他經歷。
- 既有任務卡與田上的操作維持原流程。玩家在手冊內可看到進度、尚缺的動作與完成紀念。
- 只用純 Node 測試邏輯與存檔往返。本輪不啟動遊戲、瀏覽器或圖形工具。

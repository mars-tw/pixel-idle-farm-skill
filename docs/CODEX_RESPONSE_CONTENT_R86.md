# 陽光農場 R86 雨後手記

本機開發版為 `0.1.109`。在「手札 → 圖鑑 → 追光手冊」展開「雨後手記」，可以看到三件事做了幾件，以及下一件怎麼完成。

| 手記內容 | 記錄時機 |
|---|---|
| 用雨水澆作物 | 一桶水實際澆到至少一格缺水、仍在生長的作物。 |
| 看見雨後虹光 | 虹光實際照到田裡。舊存檔若已有 R85 的虹光計數，會補記這一項。 |
| 虹光下的第一份收成 | 作物成熟、該格仍有可用虹光，而且確實收進倉庫。手記保留第一次入倉的作物名。 |

三項集滿後，可以讀到祖母寫給這份收成的短箋。重複收成會保留原來的紀錄。集章讓手冊重畫時，玩家正在看的雨後手記會保持展開。

## 離線驗證

- 雨後手記 6 項測試通過。其中 5 項檢查雨水、虹光、滿倉、批次收成與舊檔遷移，另 1 項以假 DOM 檢查手冊重畫及切換存檔。
- 既有追光手冊測試通過 21 項。R85 雨天、光照及單一步驟另通過 29 項規則測試。本輪加入 `--rules-only`，這三支可單獨檢查規則；原有完整測試入口保留瀏覽器驗收。
- 版本與離線快取一致，R22 舊存檔回歸通過。27 份新增或異動的 JavaScript 通過語法檢查。

驗證只執行 Node 資料邏輯與靜態工具。R86 的實際手機畫面、效能與完整瀏覽器回歸尚待實測。Apple 送審版本與線上版本未變更。

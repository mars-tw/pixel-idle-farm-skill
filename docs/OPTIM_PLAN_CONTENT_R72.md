# 陽光農場 R72 優化計畫：玩法深度——種田有策略、祭典有自己的小遊戲

版本 **0.1.95**／`content-r72-20261110-1`，基準 R71（0.1.94，`e774615`）。

## 來源
R59～R71 共 13 輪，三方平均停在 7.3～7.7（R71 7.53：Codex 7.8、MUSE 7.4、Claude 7.4）。內容與風格已達 7.6～8.4，拖分的是「遊戲性」（6.8～7.6）：三方歷輪一致指出「核心仍是等倒數、收成、交付」「祭典只是平日動作換皮」「選擇看不出後果」。本輪改做玩法擴充，不再修細節。

## A 線：種田策略（派 Codex）
1. **三種照顧方式**（每格田、每次種植可選一種，種下後在田格上用小圖示看得出）：
   - 「勤澆水」：成熟時間 −25%，產量不變（已有澆水機制整合成這個選項）。
   - 「施堆肥」：消耗 1 份堆肥，產量 +1，且有 30% 機率得到「優質」作物（訂單收購價 ×1.5、評比 +1 分）。
   - 「放著長」：不額外照顧，成熟時間 +20%，但收成時得 1 包種子（省錢路線）。
2. **優質作物**：背包與訂單區分一般／優質；訂單卡顯示「交優質可多拿 N 金」；作物評比把優質納入加分來源。
3. **作物季節**：目前季節的當季作物成長 −15%，非當季 +15%；種子欄標示「當季」。
4. 前十分鐘節奏（R65 測試的最長等待 ≤10 秒）與經濟不可崩壞；照顧方式選擇在種子欄或田格長按／點選後出現，不新增擋路彈窗。
- 驗收：`scripts/test-content-r72-farming.js`（三種方式的時間、產量、種子、堆肥消耗、優質機率以固定亂數驗證、訂單加價、評比加分、季節加減、前十分鐘節奏）。

## B 線：祭典小遊戲「擺攤叫賣」（派 MUSE）
5. 收穫祭期間，祭典攤位多一個「擺攤叫賣」：60 秒小遊戲，畫面上方輪流出現鄰居顧客（帶需求泡泡，例如「我要番茄」「甜的」），玩家點背包裡符合的作物／料理遞給他。答對 +分、連續答對有連擊加成、答錯或逾時顧客離開。結束依分數給 1～3 星：獎勵金幣、祭典獎章，三星給限定裝飾「金色攤位旗」。每場可玩 2 次，取最高分。
6. 顧客需求只出玩家已解鎖的物品；物品不夠時用「代幣」模式（不消耗背包，只算分）避免卡住。
- 程式放新檔 `src/festival-stall-r72.js`（加進 index.html 與 sw.js），透過既有 API 接線；CSS 追加在 `src/content-r58b.css` 檔尾標 R72B；需要的像素圖用 MUSE `muse.image_generation` 產生並記入 `assets/generated/content-r72/manifest.json`。
- 驗收：`scripts/test-content-r72-stall.js`（計分、連擊、逾時、星等與獎勵、每場兩次、需求只出已解鎖物品、代幣模式）＋Playwright 截圖可玩。

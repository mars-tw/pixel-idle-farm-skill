# 陽光農場 R74 優化計畫：照顧方式只在種田時出現、擺攤叫賣公平好拿星、雜項文字修正

版本 **0.1.97**／`content-r74-20261110-1`，基準 R73（0.1.96，`589462f`）。

## 來源：R73 三方評分（33 張，每位評兩次）
Codex 7.9／8.0、MUSE 7.8／7.4、Claude 7.3／7.3，平均 **7.62**。Claude 系統分 6.9～7.0 為主要拖分；兩次評語共同重點如下。

## A 線（派 Codex）
1. **照顧方式只在種田時出現**：平時不常駐；點空田或拿種子準備種下時，在該格田旁彈出三段按鈕（含效果一句），種下或點別處即收起。手機直式不得與任務卡、陽光提示疊成一大塊。祭典廣場、NPC 對白附近不得出現。
2. **田邊提示計數正確**：「已種 n／3 格」n 等於畫面上實際有作物的格數；可收成時只顯示「可收成」，不同時出現「種滿再澆水」與陽光倒數字樣。
3. **雜項文字**：任務卡章名／任務名在桌面寬度足夠時不截斷，收合時第二行不被裁；「木材」「木料」統一為「木料」；升級提示「獲得」與「新解鎖」不重複；作物評比結果獎勵只寫一次；建造卡缺口文字不碎行（卡片加寬或改為條列兩行）；雞舍餵食槽加名牌；三個設施都顯示名牌。
- 驗收：`scripts/test-content-r74-systems.js`、`scripts/test-content-r74-layout.js`。

## B 線（派 MUSE）
4. **擺攤叫賣公平**：顧客需求至少 70% 來自背包有貨的物品；分數列顯示「代幣 N」；新顧客出現時清除上一位的回饋，答對／答錯以顧客卡上的短動畫與加分飄字呈現；0 星給保底 5 金並用鼓勵語氣；結算只留一句建議；小麥等無口味物品不顯示「生活用品」之類非口味標籤；商品卡文字不碎行。
5. 驗收：以「背包有 4 種貨」的狀態模擬 3 局（固定亂數＋規則化的作答策略：只答有貨且符合的），至少 2 局拿到 1 星以上。
- 驗收：`scripts/test-content-r74-stall.js`。

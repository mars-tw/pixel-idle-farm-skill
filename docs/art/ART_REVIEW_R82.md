# R82 改前美術審查

狀態：VERIFIED（四視口實際無頭截圖）。證據：compare/before；390×844、844×390、1032×1376、1366×600，各 welcome／farm／daily／basket。

總評：4/10。農場已有真像素地形與可辨識建築，但第一次進場像網頁公告；專屬餐籃與祖母敘事幾乎全靠文字。美術完整度不等於素材數量。

最致命三項：
1. 歡迎頁沒有一張餐籃、便箋或人的近景。純白卡與綠色標題無法說出本作賣點。
2. 日誌、收藏、餐籃共用表單骨架；抉擇與故事結果沒有插圖，頁面層級沒有情緒差異。
3. 黑綠遮罩壓暗整個世界，圓角白按鈕像工具網站；光斑應是葉隙圓斑，現有直光柱太硬。

逐畫面：
- welcome：手機中央薄荷白卡，38px 以外大多是文字；iPad 背景佔比大但被壓暗。主次按鈕缺材質、關閉焦點應保留但改暖色。
- farm：角色動作與建築有基礎；地圖草色灰黃、UI 白色長條割裂，手機工具列和功能列像兩排網頁表單。標題缺 Logo 識別。
- daily：橫向能放下但只有單張任務與空隙；應用農務小物與格紋紙給目標視覺。禁用額外大圖擠出返回鈕。
- basket：iPad 中央小表單沒有餐籃；紙頁與分頁同綠色。抉擇應有餐籃物件，送達應有門廊／共坐插圖。

MUSE 納入：同意模板外觀、角色缺近景、光柱、圖示不統一與故事高潮缺圖的批評；MUSE 僅看歷史五張截圖，本輪沒有把其「無程式可查」當成目前 repo 狀態。角色地圖已有真逐幀，不因靜幀看不出動態而宣稱無動畫。藍焦點框是鍵盤可達性功能，改色保留，不直接移除。

改後驗收：紙籤／藤編／格紋三種真實材質；入口有可辨識近景；餐籃故事有畫面；地圖不被新插畫取代；四視口仍可達。

## 改後嚴格回讀

狀態：VERIFIED；已看同視口對照、原生接觸表與十張商店縮圖，含冷啟動主圖解碼後的重擷取。

- welcome：餐籃與主角近景建立第一眼主題，紙面與金木牌相符。手機 Logo 細節仍比 App 圖示弱，沒有把小字標當唯一識別。
- farm：UI 已離開薄荷白圓角模板，硬邊光柱已移除。地圖本體屬既有像素素材，農夫地圖衣裝與肖像的草帽／紅巾仍有連續性缺口，不能稱全角色重繪完成。
- daily：新澆水壺／麥穗／餐籃物件提高目標辨識，橫向保留可點動作。單卡農務與文字規則仍偏功能性；本輪未用真人資料證明留存改善。
- basket／note：雙圖清楚區分門邊與茶桌，送達頁有專屬故事畫面；較矮橫向收起選項縮圖，保留主要故事插圖與文字行動。其抉擇理解度仍需真人盲測。
- 商店：十張都是實際 UI 與真實進度，四個敘事頁可見農夫近景。iPad 的可玩世界保留較大面積，紙本 UI 有較強對比；這是構圖取捨，尚無五人跨遊戲混排證據。

本輪自評：7/10。已解決入口無圖、故事無畫面與通用 UI 三項主問題；全套地圖衣裝、專用姿勢幀與真人辨識證據仍缺。Apple 4.3 風險維持中，不能只靠美術自評稱低。

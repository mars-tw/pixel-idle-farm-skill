## 1. 這輪做了什麼

### 好玩

| ID | 改了什麼 | 為什麼更好玩 |
|---|---|---|
| F1 | **招牌玩法「陽光光斑」**（`src/game.js`，不依賴 DOM）。種下第一株約 4 秒後，第一道光落在田上，之後每 40 秒一道（晴朗天氣 28 秒），每道停 16 秒、最多照 2 格。光裡種下或澆水會立刻推進 30% 成長時間（上限 3 分鐘），光裡收成多 1 份、多 2 經驗；每格每道光只算一次。雨、雪、霧、暴風雨不出光斑，離線也不累積 | 以前主動玩和放著不管的收益一樣，核心循環和一般放置農場沒有差別。現在玩家有理由一直看著田、搶時機，天氣也開始影響決策。這是用遊戲名稱「陽光」做出來的玩法，不是通用功能 |
| F2 | 第一道光出現時，鎮長用一句話說明規則（只說一次）。在光裡成功時，會出現金色光點、「☀ 陽光豐收 +1」／「☀ 陽光催芽」浮字、專屬三音音效，toast 也標出「（陽光 +1）」 | 抓到時機的回饋清楚又好看 |
| F3 | 任務列加一行提示。等作物長大時顯示「⏳ 最快 N 秒成熟・澆水更快」；光斑出現時改成「☀ 陽光 N 秒・光裡種澆收有加成」。「前往」也會優先帶玩家去被光照到的那一格 | 開局等待時知道還要多久、現在能做什麼 |
| F4 | 走路途中按「前往」或其他「走過去做事」的指令，會直接改道，不再跳出「先走完這段路，再接著做。」 | 操作不再被擋，手感比較順 |
| F5 | 收成時飛出去的是作物，終點是倉庫格，抵達時倉庫數字會跳一下。以前飛出去的是金幣，但收成其實沒拿到錢。連收改成「連收 ×N」，第 3 次以後變金色、第 5 次以後更大；`Level up` 改成「升級！」 | 回饋和實際結果一致，也不再出現英文 |
| F6 | 背景音樂。用本機 AI 派工器 `music`（`ace_step_turbo`）生成 30 秒田園曲，後製成 25.2 秒無縫循環的 OGG／M4A。第一次互動後才開始播；關音效、關音樂、音量 0 或切到背景時會停。設定頁新增「背景音樂」開關 | 以前整個遊戲只有合成音效，沒有配樂 |

## 4. 八大面向對照

1 美術：只做程式化光影，沒有新圖。2 按鈕：資源列遮擋、fit 切換鈕重疊、toast 壓住對話框都已修正並有守門。3 選單：設定卡多一行開關，沒有增加長捲動。4 人物、7 角色樣子：本輪沒有改，夜間亮度閘門照常通過。5 地圖：晴天加了光影層次。6 技能：光斑有倒數條和成功回饋，只有真的成功時才計數。8 動作：改道會取消舊路線和還沒結算的作用幀，不會在錯誤的目標上結算。

## 5. 未完成與風險

- **沒有真人試玩數據。** 光斑的參數（40 秒間隔、30% 加速、+1 產量）是設計值，還沒有留存或趣味性的實測，不能用 E2E 全綠說明它已經好玩。
- 光斑會讓主動玩家的經濟成長變快。既有經濟測試只模擬放置收益，沒有涵蓋主動加成後的節奏；需要時再調 `SUNPATCH` 常數。
- 幫手機器人在線上幫忙收成時，碰巧落在光裡也會拿到加成；離線結算不會。
- 連按「前往」會打斷正在進行的動作。因為會在新目標重新做一次，不會吃掉資源，但手感上可能看起來像沒反應。
- 背景音樂是 AI 生成曲，還沒經過人耳審核；ACE-Step 的精確模型版本派工器沒有回報。兩個音檔約 680KB，已加入 SW 預快取，首次安裝的下載量會多這些。
- 這輪沒有生成新的 2D 角色、作物或地形美術。持竿、捧收成等專用動作仍沿用 R75 的缺件清單，要等 gpt-image-2 管線可用。
- 沒有 push、沒有部署，也沒有碰任何商店。

## A 線：系統與內容（派 Codex）
1. **交付前看得到結算**：共用作物的訂單卡寫「交付後剩 X 份・主線還需 Y 份」。不夠同時完成時，交付鈕旁顯示警告，並在確認時再提醒一次。
   - 驗收：單元測試持有 4、主線需 2、訂單需 2／4 時的文字。
2. **第一個玩家選擇**：交完老農班伯、市集開放時，讓玩家二選一「先做農家麥餅（主線）」或「先接蘿拉的 2 份小麥單（賺錢）」。兩條路都可行、都會回到主線，任務列依選擇切換追蹤；選擇結果記在存檔，任務列可再切換。
   - 驗收：單元測試兩種選擇都能在不卡關的情況下完成第一章，任務列追蹤目標隨選擇改變。
3. **每日印章冊精簡**：市集未開放時，第三項改成一行鎖定列「市集開放後解鎖：賣出一份作物」，不再佔一整張卡。頁面頂部固定「返回農場」與關閉鈕。
   - 驗收：單元測試與字串。
4. **材料單位一致**：HUD 的「材料 N」改為顯示主要材料，例如「木料 X・石材 Y」，或點開後列出各材料。建造卡、升級卡、HUD 用同一套名稱與圖示。
   - 驗收：單元測試建造需求的材料名稱都能在 HUD 找到對應。
5. **升級提示改成米色結算卡**：升級與里程碑卡改用與其他面板相同的米色紙張樣式，位置避開工具列與角色（右上或左下安全區）。
   - 驗收：CSS 規則與截圖。

## B 線：版面（派 MUSE）
6. **矮螢幕對話回到下方**（改 R32 規則）：1366×600 與 844×390 時，對話放在工具列上方的安全區；高 ≤ 30%，台詞完整兩行，「略過」與「繼續」不與文字重疊；說話者被蓋到時，鏡頭微調讓說話者露出。同步更新 `test-content-r32-layout.js` 的「top ≤ 24」斷言，並在回報說明。
   - 驗收：兩種尺寸量測文字與按鈕交集 0、說話者可見、對話框高 ≤ 30%。
7. **陽光看得見**：受光田格加上暖色邊框與小太陽圖示，並顯示剩餘秒數的細進度條；選取受光田格時，提示「在光裡：生長加速・收成 +1」。
   - 驗收：瀏覽器量測受光格有邊框元素，近白像素 < 3%。
8. **大型面板開啟時收合 HUD**：打開訂單、升級、手記、建造、設定時，左上任務卡自動收成一行，種子欄隱藏；關閉後恢復。
   - 驗收：量測面板開啟時任務卡高度 ≤ 56px。
9. **手機橫式對話與互動對象**：844×390 時，說話者與互動對象在對話期間保持在可視區（鏡頭置中到說話者）；互動鈕不蓋到他們。
   - 驗收：量測說話者完整在畫面內。
10. **選取框只框一格**：選取框寬度等於一格田，在四種尺寸下都不跨兩格。
    - 驗收：量測選取框寬度 ≈ 一格寬（±2px）。

# 陽光農場 內容優化 R82 計畫（精簡版）

依據 R81 評審：Codex 8.1、Claude 6.4（`REVIEW_CONTENT_R81.md`）。照使用者指示，重心放在遊戲內容；介面只修會讓玩家看不懂或卡住的地方。評審仍只用 Codex 一次＋Claude 一次，截圖只抽看改到的畫面，完整測試只在收尾跑一次。

## A 線（Codex）：指示只有一個來源、永遠讀得完
1. 任務卡、祖母手記、手札「現在做」、任務清單用同一個來源；故事往前推進後全部同步，不再停在開頭或彼此打架（R81 圖 122、136～138、143、145）。
2. 任務卡的說明不被按鈕蓋住或截斷：空間不夠時按鈕自己佔一行；收合後也是一句完整的話（圖 34、52、53、75、76、79、80、102、104、129）。
3. 提示不互相矛盾：還沒成熟不寫可收成（圖 132）；結算與田上狀態一致（圖 106）；田裡有作物時不叫玩家去種（圖 81）。
4. 拿掉對話時任務卡下方的空白卡片（圖 114、120）與工具列旁的米色殘影（圖 121、122）；每個結果視窗都有看得到的關閉或繼續（圖 90）。
5. 同一畫面最多一顆黃色主按鈕：手機右下的作物狀態改成非主按鈕樣式；有田邊動作列時，任務卡只寫狀態、不放像按鈕的框。
6. 測試：`scripts/test-content-r82-guidance.js`、`scripts/test-content-r82-guidance-layout.js`（四尺寸）。

## B 線（Codex）：舊麥種兩條路線各有自己的玩法
1. 二選一的選項不寫金幣，只寫「地圖會多什麼、之後能做什麼」；數字留在手札。
2. 「種回田裡」：藍布老麥田可以種一種新的傳家作物「藍布老麥」，要在兩個不同的遊戲日各照到一次光才會成熟，收成後拿來做一道專屬料理或交一張專屬訂單。
3. 「先封存起來」：開出鎮誌支線，地圖上分天出現三樣舊物（例如舊種子籤、褪色照片、帳本一頁），每找到一樣就演一小段鎮長葛瑞的回憶；三樣齊了，封存箱旁多一件永久擺飾。
4. 選完之後鏡頭帶到新出現的物件、停約 2 秒（R81 圖 140 看不到新物件）。
5. 兩條路線各至少一種另一條沒有的操作或事件；選項文字不出現「金」字。
6. 測試：`scripts/test-content-r82-branches.js`。缺圖照例列在回報裡，由主控請 MUSE 補。

## C 線（Claude 子代理）：前幾分鐘有得選、等待時有事做
1. 等光、等成熟、等曬乾的倒數期間，田邊偶爾出現可以順手做的小事（例如撿落穗、趕走啄田的麻雀、拔一株雜草），點了就給一點小收穫，不打斷原本的流程；前十分鐘不出現超過三秒只能看倒數的空檔。
2. 第一次收成之後，任務卡同時給兩個一樣有效的目標讓玩家自己挑（例如先送餐籃，或先修釣台），兩邊都通往主線。
3. 早市取捨做成真的二選一：兩邊都寫最終拿到什麼（「現在收：2 份交早市，得 14 金」對「等 6 秒：3 份小麥＋陽光 2，但錯過早市」），換算後兩邊價值差距在 15% 以內；田上標籤不預先寫「等光再收」。
4. 擺攤商品卡加上作物名稱，番茄、草莓等一眼分得出來；追光手冊改寫成「小麥 1／4 枚」這種按作物計的寫法。
5. 測試：`scripts/test-content-r82-play.js`。

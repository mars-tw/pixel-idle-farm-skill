# 陽光農場 R73 優化計畫：讓新玩法看得懂、玩得順

版本 **0.1.96**／`content-r73-20261110-1`，基準 R72（0.1.95，`9e78d6b`）。

## 來源：R72 三方評分（33 張，每位評兩次）

|---|---|---|---|

R72 新玩法方向被肯定（Codex 兩次 8.0 以上、無嚴重問題），但 MUSE、Claude 指出新玩法「看不懂」：
1. 照顧方式只有左上三顆小按鈕，沒有效果說明；字蓋在圖示上或被切掉，還會被樹叢壓住、手機上擠在一起。
2. 擺攤叫賣的商品卡只有品名，玩家答不出「想吃酸的」；背包明明有貨卻顯示代幣模式；商品沒有圖示。
3. 結算看不到幾分拿幾星，兩句說明重複；結算視窗疊在祭典攤位視窗上。

## A 線：照顧方式介面（派 Codex）
1. 照顧方式改成種子列內的一列分段按鈕（圖示＋名稱，名稱不得被裁、不與圖示重疊），選中的那顆下方一行寫效果（例如「施堆肥：產量 +1，30% 優質，用掉 1 份堆肥（剩 3）」）；四尺寸都不被地圖物件遮擋（固定在 UI 層）。
2. 田格上的照顧方式小圖示有 title／長按說明。
- 驗收：`scripts/test-content-r73-care.js`（四尺寸：三顆按鈕名稱完整、不重疊、效果說明可見且隨選擇改變）。

## B 線：擺攤叫賣看得懂（派 MUSE）
3. 每張商品卡加上物品像素圖示（沿用遊戲既有作物／料理圖）與口味標籤（甜、酸、清爽、熱熱的），口味題答案一眼可推。
4. 只要背包有該物品就用背包模式；只有沒貨的那一格標「用代幣」，頂部不再寫整場「代幣模式」。
5. 開始畫面與結算顯示星等門檻（60／140／240 分），結算只留一句改善建議；開始叫賣時關閉祭典攤位視窗，結算回到攤位時再開。
- 驗收：`scripts/test-content-r73-stall.js`（商品卡有圖示與口味、模式判斷、門檻文字、視窗不疊加）。
